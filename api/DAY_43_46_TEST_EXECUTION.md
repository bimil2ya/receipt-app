
#### 📸 Step 2: 영수증 촬영 및 자동 인식 (예상 시간: 10분)
```

  - 편의점 영수증 (금액: 12,000원, 상호: GS편의점)
  - 식당 영수증 (금액: 25,000원, 상호: 서울식당)

사용자 행동 (각 영수증별 반복):
  1. 카메라 버튼 클릭
  2. 영수증을 카메라에 정렬
  3. 촬영 버튼 클릭
  4. 자동 처리 대기
  5. 추출된 정보 확인

측정 항목:
  ☐ 카메라 권한 확인
  ☐ 사진 촬영 시간
  ☐ OCR 처리 시간 (로그)
  ☐ 추출된 금액 정확도
  ☐ 추출된 상호 정확도
  ☐ 음성 알림 재생
  ☐ 오류 발생 여부

성공 기준:
  ✅ OCR 정확도 > 85% (3개 중 2.5개 이상)
  ✅ 처리 시간 < 5초
  ✅ 음성 알림 정상 작동
  ✅ 오류 없음
```

## 🌐 Day 44-46: 네트워크 안정성 테스트

### 개요
```
목표: 불안정한 네트워크 환경에서의 동작 검증
참여자: Group C (Day 44-45) + Group D (Day 45-46)
총 시간: 3일 × 5명 = 15명 세션

테스트 환경:
  - 3G 시뮬레이션 (느린 네트워크)
  - WiFi 불안정 (주기적 끊김)
  - 완전 오프라인 (항공기 모드)
```

### 테스트 시나리오

#### 1️⃣ Scenario A: 3G 느린 네트워크 (Day 44)

##### 세팅
```
네트워크 설정:
  - 속도: 1Mbps (다운로드)
  - 지연: 100ms
  - 손실: 2-5%
  
Chrome DevTools 설정:
  1. F12 → Network 탭
  2. Throttling: "Slow 3G" 선택
  3. 또는 Custom: Download 1000 kbps, Latency 100ms
  
Android/iOS 시뮬레이션:
  - Network Link Conditioner (Mac) 또는
  - 기기 개발자 옵션에서 네트워크 제한 설정
```

##### 테스트 절차
```
1. 느린 네트워크 활성화
2. 앱 실행
3. 영수증 촬영 및 업로드
4. 진행 상황 관찰
5. 결과 확인

측정 항목:
  ☐ 로딩 시간
  ☐ OCR 처리 시간
  ☐ 업로드 진행률 표시
  ☐ 완료 여부
  ☐ 오류 발생 여부
  ☐ 사용자 만족도 (설문)

성공 기준:
  ✅ 작업 완료 (시간 초과 주의)
  ✅ 오류 복구 자동 처리
  ✅ 진행 상황 표시 명확
```

#### 2️⃣ Scenario B: WiFi 불안정 (주기적 끊김) (Day 45)

##### 세팅
```
네트워크 설정:
  - 주기적 연결 끊김 (5초 주기)
  - 복구 시간: 2-3초
  
macOS에서 tc (traffic control) 명령:
  sudo tc qdisc add dev en0 root netem loss 50% delay 100ms
  (또는 Network Link Conditioner 사용)
  
또는 WiFi 라우터:
  - WiFi 신호 약화 (물리적 거리 증가)
  - 주기적으로 WiFi 끄고 켜기
```

##### 테스트 절차
```
1. 불안정한 WiFi 활성화
2. 앱 실행
3. 영수증 촬영 및 업로드 시작
4. 네트워크 끊김 이벤트 발생 (의도적)
5. 자동 복구 관찰
6. 최종 결과 확인

측정 항목:
  ☐ 네트워크 끊김 감지 시간
  ☐ 자동 재시도 동작
  ☐ 재시도 횟수
  ☐ 최종 성공 여부
  ☐ 사용자 피드백 명확도
  ☐ 사용자 만족도

성공 기준:
  ✅ 네트워크 복구 후 자동 재개
  ✅ 중복 전송 없음
  ✅ 최종 성공률 > 95%
  ✅ 사용자가 상황 이해 (설문)
```

#### 3️⃣ Scenario C: 완전 오프라인 + 온라인 복귀 (Day 46)

##### 세팅
```
오프라인 상태:
  iOS: 항공기 모드 ON
  Android: 항공기 모드 ON
  
또는:
  - WiFi OFF
  - 모바일 데이터 OFF
```

##### 테스트 절차
```
Phase 1 - 오프라인 저장 (5분)
  1. 오프라인 상태 확인
  2. 영수증 촬영
  3. 저장 시도
  4. 로컬 저장 확인
  
  측정 항목:
    ☐ 오프라인 표시 명확도
    ☐ 로컬 저장 성공 여부
    ☐ 오류 메시지 명확성
    ☐ 저장 완료 피드백

Phase 2 - 온라인 복귀 + 동기화 (5분)
  1. 온라인 상태 복구 (항공기 모드 OFF)
  2. 자동 동기화 시작 대기
  3. 동기화 진행률 관찰
  4. 완료 확인
  
  측정 항목:
    ☐ 온라인 감지 시간
    ☐ 자동 동기화 시작
    ☐ 동기화 시간
    ☐ 최종 성공 여부
    ☐ 데이터 무결성 (중복 없음)
    ☐ 사용자 피드백 명확도

성공 기준:
  ✅ 오프라인 저장 성공률: 100%
  ✅ 온라인 복귀 감지: < 5초
  ✅ 자동 동기화 성공: > 99%
  ☐ 중복 전송: 0건
  ✅ 사용자 만족도: > 80%
```
