## 🎯 테스트 시나리오

### Scenario 1: 기본 사용 흐름 (Day 41-43)
**목표**: 자연스러운 일반 사용

```
1단계: 앱 설치 및 첫 실행
   - 앱 다운로드 (1-2분)
   - 초기 설정 (2-3분)
   - 권한 요청 처리 (카메라, 저장소)
   ✅ 기준: 10분 내 완료

2단계: 영수증 촬영 및 자동 인식
   - 카페 영수증 촬영
   - Vision OCR 실행 (자동)
   - 금액/상호 자동 추출
   ✅ 기준: 정확도 > 85%, 응답시간 < 5초

3단계: 저장 및 동기화
   - 자동 저장 (음성 알림)
   - Google Drive 동기화
   - 완료 피드백 (시각+음성)
   ✅ 기준: 동기화 성공률 > 99%

4단계: 분석 데이터 확인
   - 분석 대시보드 열기
   - 월별/상점별 통계 확인
   - 차트 데이터 시각화
   ✅ 기준: UI 이해도 > 80%
```

### Scenario 2: 네트워크 안정성 (Day 44-46)
**목표**: 불안정한 네트워크에서의 동작

```
테스트 환경:
  - 3G 네트워크 (느림)
  - WiFi 불안정 (주기적 끊김)
  - 오프라인 → 온라인 복귀

테스트 항목:
  ✓ 오프라인 상태에서 영수증 저장
    - 로컬 저장 (IndexedDB) 성공
    - 오프라인 표시 명확함

  ✓ 온라인 복귀 시 자동 동기화
    - 대기 중인 항목 자동 전송
    - 중복 전송 없음
    - 충돌 해결 자동 처리

  ✓ 느린 네트워크에서 업로드
    - 이미지 청크 분할 처리
    - 진행률 표시
    - 재시도 자동 동작

기준:
  ✅ 오프라인 저장 성공률: 100%
  ✅ 동기화 성공률: > 99%
  ✅ 중복 전송: 0건
  ✅ 사용자 감지 불안정성: < 20%
```

### Scenario 3: 다양한 OS 호환성 (Day 47-49)
**목표**: iOS/Android 동등한 경험

```
iOS 테스트:
  ✓ iPhone 6s+ (2015년형 구형)
  ✓ iOS 12, 13, 14, 15 다양한 버전
  ✓ Safari 브라우저
  ✓ 음성 API (한국어 지원)
  기준: 모든 버전에서 작동

Android 테스트:
  ✓ Galaxy J2, A10 (구형 저사양)
  ✓ Android 6.0~11.0 다양한 버전
  ✓ Chrome 브라우저
  ✓ 한국어 TTS 지원 확인
  기준: 90% 이상 기기 호환

공통 테스트:
  ✓ 카메라 접근 권한
  ✓ 저장소 접근 권한
  ✓ 마이크 접근 (음성 알림)
  ✓ GPS 접근 (향후 기능)
```

### Scenario 4: 편의성 및 만족도 (Day 50)
**목표**: 사용 편의성 평가

```
정성적 평가:
  ✓ UI/UX 직관성 (1-5점)
    기준: ≥ 4점

  ✓ 기능 완성도 (1-5점)
    - 자동 인식 정확도
    - 음성 알림 유용성
    - 분석 정보 유용성
    기준: ≥ 4점

  ✓ 성능 만족도 (1-5점)
    - 응답 속도
    - 배터리 사용량
    - 데이터 사용량
    기준: ≥ 4점

  ✓ 전체 만족도 (1-5점)
    기준: ≥ 4점 (80% = 4/5)

정량적 평가:
  ✓ 작업 완료율: 100%
  ✓ 오류 발생: 0건 (또는 < 1%)
  ✓ 재시도 필요: < 5%
```

## 📊 테스트 메트릭

### 핵심 KPI (Key Performance Indicator)

| 항목 | 목표 | 측정 방법 |
|------|------|---------|
| **사용자 만족도** | ≥ 80% | 설문 점수 평균 |
| **오류율** | < 1% | 오류 발생 건수 / 총 시도 |
| **완료율** | > 95% | 시작한 사용자 중 완료한 비율 |
| **OCR 정확도** | > 85% | 정확하게 추출된 항목 / 총 항목 |
| **동기화 성공률** | > 99% | 성공한 동기화 / 시도한 동기화 |
| **네트워크 복원력** | > 99% | 오프라인→온라인 복귀 시 동작 비율 |
| **OS 호환성** | ≥ 90% | 호환되는 OS/버전 / 테스트 대상 |
| **초기 설정 시간** | < 10분 | 첫 실행부터 첫 저장까지 |

## 🎬 실행 계획

### Day 41-42: 준비 단계
```
1. 테스트 환경 구축
   - 테스트 기기 준비 (iOS 2-3대, Android 2-3대)
   - 네트워크 테스트 환경 설정 (3G, WiFi 불안정)
   - 피드백 수집 도구 준비

2. 테스트 사용자 모집
   - 60-70대 사용자 15-20명
   - 동의서 및 프라이버시 설명
   - 테스트 일정 조율

3. 사전 교육
   - 기본 조작 설명 (앱 열기, 사진 촬영)
   - 음성 알림 소개
   - 문제 발생 시 연락 방법
```

### Day 43-46: 핵심 시나리오 테스트
```
1. 기본 사용 흐름 (Day 43)
   - 각 사용자가 처음부터 끝까지 진행
   - 관찰 및 피드백 수집

2. 네트워크 안정성 (Day 44-46)
   - 오프라인 환경에서 저장
   - 네트워크 복구 후 동기화
   - 느린 네트워크에서 업로드
```

### Day 47-49: 호환성 테스트
```
1. iOS 테스트 (Day 47)
   - iPhone 구형 모델 테스트
   - 다양한 iOS 버전

2. Android 테스트 (Day 48)
   - Galaxy 저사양 모델 테스트
   - 다양한 Android 버전

3. 공통 호환성 (Day 49)
   - 권한 요청 처리
   - 브라우저 호환성
```

### Day 50: 최종 평가 & 배포
```
1. 피드백 수집 및 분석
   - 만족도 점수 집계

   - 개선 사항 우선순위

2. 긴급 버그 수정
   - Critical 이슈만 Day 50 처리
   - 기타는 향후 업데이트로

3. 최종 배포
   - 프로덕션 빌드 생성
   - App Store/Play Store 제출
   - 버전 관리 및 릴리스 노트
```

## 📝 피드백 수집 도구

### 설문 항목 (Likert Scale 1-5)

```
1. 앱 사용이 얼마나 쉬웠나요?
   1: 매우 어렵다 ~ 5: 매우 쉽다

2. 자동 인식 기능이 정확했나요?
   1: 거의 틀렸다 ~ 5: 항상 정확했다

3. 음성 알림이 도움이 되었나요?
   1: 방해만 됨 ~ 5: 매우 유용함

4. 분석 정보가 유용했나요?
   1: 쓸모없음 ~ 5: 매우 유용함

5. 전체적으로 만족하세요?
   1: 매우 불만족 ~ 5: 매우 만족
```

### 개방형 질문

```
1. 가장 좋았던 기능은?
2. 가장 불편했던 부분은?
3. 개선되었으면 좋을 기능은?
4. 추가 의견은?
```
