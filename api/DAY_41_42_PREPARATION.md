### 1️⃣ 테스트 환경 구축 (Day 41)

#### 1.1 기기 준비
```
iOS 기기:
  ☐ iPhone 6s+ (2015년형) - 구형 호환성 테스트
    - iOS 12, 13, 14, 15 버전 확인
    - Safari 브라우저 확인
    - 음성 API 한국어 지원 확인
  
  ☐ iPhone 12/13 (현대 기기) - 성능 테스트
    - 최신 iOS 버전 확인

Android 기기:
  ☐ Galaxy J2 (2015년형) - 저사양 호환성
    - Android 6.0 확인
    - Chrome 브라우저 확인
  
  ☐ Galaxy A10 (2019년형) - 중사양
    - Android 10 확인
    - Chrome 브라우저 확인
  
  ☐ 최신 Galaxy 모델 - 성능 테스트
    - 최신 Android 버전 확인
```

#### 1.2 네트워크 테스트 환경
```
준비 사항:
  ☐ 3G 네트워크 시뮬레이션
    - 속도: ~1Mbps (느린 다운로드)
    - 지연: ~100ms
    - 손실: ~2-5%
    - 도구: Chrome DevTools Throttling

  ☐ WiFi 불안정 환경 시뮬레이션
    - 주기적 끊김 (5초 주기)
    - 재연결 테스트
    - 도구: Network Link Conditioner 또는 macOS tc 명령

  ☐ 완전 오프라인 환경
    - 항공기 모드 활성화
    - 로컬 저장 검증

테스트 방법:
  1. Chrome DevTools → Network → Throttling
  2. 속도 프리셋 선택 (Slow 3G, Fast 3G)
  3. 또는 Custom 설정:
     - Download: 400 kbps
     - Upload: 400 kbps
     - Latency: 100ms
```

#### 1.3 기기 설정
```
모든 기기:
  ☐ 카메라 권한 설정
  ☐ 저장소 권한 설정
  ☐ 마이크 권한 설정 (음성 알림)
  ☐ GPS 권한 설정 (향후 기능)
  ☐ 최신 브라우저 버전
  ☐ 쿠키/로컬스토리지 초기화

iOS 추가:
  ☐ Safari 개발자 모드 활성화
  ☐ 콘솔 접근 확인

Android 추가:
  ☐ Chrome 개발자 모드 활성화
  ☐ USB 디버깅 활성화 (필요시)
```

#### 1.4 피드백 수집 도구 준비
```
디지털 도구:
  ☐ Google Form 설문지 (Likert 5점 + 개방형)
  ☐ 테스트 로그 수집 스크립트
  ☐ 스크린샷/비디오 저장소 준비

물리적 도구:
  ☐ 테스트 노트 (인쇄본)

  ☐ 체크리스트 (기기별)

### 2️⃣ 테스트 사용자 모집 (Day 41-42)

#### 2.1 사용자 모집 기준
```
필수 조건:
  ✓ 나이: 60-70세
  ✓ 기술 경험: 낮음 (스마트폰 기본 사용만)
  ✓ 한국어: 모국어
  ✓ 스마트폰 소유: iOS 또는 Android

선호 사항:
  ✓ 다양한 직업 (은퇴자, 직장인 등)
  ✓ 성별 균형 (남/여 각각 ~50%)
  ✓ 지역 다양성 (대도시 + 지방)
  ✓ 안경/청력 상태 다양함
```

#### 2.2 모집 채널
```
방법 1: 지인 추천
  - 주변 친구/가족 소개
  - 지역 커뮤니티 센터
  - 효율성: 높음, 신뢰도: 높음

방법 2: 온라인 플랫폼
  - 당근마켓 (지역 기반)
  - 네이버 카페 (60+)
  - 번개장터
  - 효율성: 중간, 신뢰도: 중간

방법 3: 전문 모집 업체
  - 시장조사 회사
  - 사용자 테스트 플랫폼 (userlytics, respondent 등)
  - 효율성: 높음, 신뢰도: 높음, 비용: 높음

목표: N=15-20명, 최대한 다양한 배경
```

#### 2.3 사용자 동의서
```
작성 내용:
  1. 프로젝트 설명 (2-3줄)
  2. 테스트 내용 (30분, 4가지 작업)
  3. 데이터 수집 범위
  4. 개인정보보호
  5. 서명 (사용자 + 테스터)

주의사항:
  - 간단하고 명확한 한국어
  - 큰 글씨 (시각 장애 고려)
  - 법률 검토 (선택)
```

### 3️⃣ 사전 교육 준비 (Day 41-42)

#### 3.1 교육 자료
```
📱 기본 조작 가이드
  ☐ 앱 설치 (App Store/Play Store)
    - 단계별 스크린샷
    - 큰 글씨 (14pt+)
    - 예상 시간: 2-3분

  ☐ 앱 처음 실행
    - 권한 요청 설명
    - "허용" 버튼 찾기
    - 예상 시간: 1-2분

  ☐ 영수증 촬영
    - 카메라 열기
    - 영수증 정렬
    - 촬영 버튼 찾기
    - 예상 시간: 1-2분

  ☐ 결과 확인
    - 자동 추출 결과 보기
    - 음성 알림 확인
    - 예상 시간: 1-2분

총 예상 시간: 10분 이내 (성공 기준)
```

#### 3.2 교육 방식
```
방법 1: 동영상 가이드
  - 5분 영상 (자막 필수)
  - 유튜브 또는 웹 페이지에 임베드
  - 반복 시청 가능
  - 비용: 낮음, 효과: 중간

방법 2: 개별 지도
  - 테스터가 직접 설명
  - 실시간 문제 해결
  - 사용자 편의성: 높음
  - 비용: 높음 (시간), 효과: 높음

방법 3: 그룹 교육
  - 5-10명씩 한 그룹
  - 오프라인 워크숍
  - 사용자 만족도: 높음
  - 비용: 높음, 효과: 높음

추천: 방법 2 (개별 지도) → 영상 자료 지원
```

#### 3.3 문제 해결 가이드
```
상황 1: 앱 설치 안 됨
  ☐ 스토어 재시작
  ☐ 인터넷 연결 확인
  ☐ 기기 저장공간 확인
  ☐ 기기 재부팅

상황 2: 앱 실행 안 됨
  ☐ 권한 확인
  ☐ 브라우저 새로고침 (PWA)
  ☐ 캐시 초기화
  ☐ 다른 앱 종료

상황 3: 카메라 에러
  ☐ 카메라 권한 확인
  ☐ 다른 앱에서 카메라 사용 확인
  ☐ 렌즈 청소
  ☐ 앱 재시작

상황 4: 음성 나오지 않음
  ☐ 음량 확인
  ☐ 마이크/스피커 권한
  ☐ 조용한 모드 해제
  ☐ 한국어 음성 설정 확인

연락처:
  - 긴급 핫라인 (카카오톡/전화)
  - 예상 응답 시간: < 5분
```

```

  - 커뮤니티 센터
  - 사무실
  - 장점: 개인적, 편안함
  - 고려사항: WiFi, 전원, 조명

옵션 2: 온라인 (원격)
  - Zoom/Google Meet
  - 화면 공유로 진행
  - 장점: 편리, 비용 절감
  - 고려사항: 인터넷 안정성

추천: 옵션 1 (오프라인) + 백업 온라인
